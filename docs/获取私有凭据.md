# 如何获取私有凭据

集成需要 5 个值，都从「中燃在线」微信小程序的请求里抄。这份文档把步骤写细，照着做就行。

> 本文所有示例都是**假数据**，请以你自己抓到的为准。

---

## ⚠️ 先说最关键的一点

**微信小程序的流量不走系统 HTTP 代理。**

```
❌ Charles / Fiddler / 手机 WiFi 代理   → 抓不到小程序 ✗
✅ 必须用「VPN 模式」（本地 VPN 拦截）的工具
```

---

## 一、准备工具

| 平台 | 推荐 | 说明 |
|---|---|---|
| **Android** | **Reqable** | 原 HttpCanary 团队出品，免费够用 |
| | HttpCanary | 老牌工具 |
| | Stream | 免费，UI 简单 |
| **iOS** | **Surge** | 付费但最好用 |
| | Loon / Quantumult X | 同类替代 |
| | Stream | 免费 |

**安装后必须做的事：**

1. 打开工具的 **VPN 抓包模式**（不是 WiFi 代理模式）
2. **安装并信任 CA 证书**
   - Android：App 里点「安装证书」→ 设置里「信任用户证书」
   - Android 14+：可能需要在「加密与凭据 → 安装证书 → CA 证书」手动导入
   - iOS：设置 → 通用 → VPN与设备管理 → 装描述文件 → 通用 → 关于本机 → 证书信任设置 → 信任该根证书

---

## 二、抓包步骤

1. **打开抓包工具**，确认处于 VPN 抓包状态
2. **打开微信** → 搜索小程序「**中燃在线**」
3. 进入小程序，点「**燃气缴费**」或「我的」，**能看到余额**（这一步会触发我们要的那个请求）
4. 回到抓包工具，在历史记录里搜索：

   ```
   findCustInfoByCustCodeAndCustName
   ```

5. **点开这条请求**

---

## 三、从请求里抄 5 个值

### 请求头（Request Headers）

| 字段名 | 抄什么 | 假数据示例 |
|---|---|---|
| `accessToken` | 完整值（32 位十六进制） | `0123456789abcdef0123456789abcdef` |
| `userId` | 完整值（9 位数字） | `123456789` |
| `x-mas-app-info` | **完整值，最长的那个** | `aaahg10001/168006.XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX..123456789` |

### 请求体（Request Body）

请求体是表单格式，或者是一段 `custCode=xxx&custName=yyy&...`：

| 字段名 | 含义 | 假数据示例 |
|---|---|---|
| `custCode` | **燃气户号**（10 位数字，缴费单上也有） | `1234567890` |
| `custName` | **户主姓名**（全名，不是带 `*` 的） | `张三` |

> 如果请求体里名字是 `*三` 这种打了码的，说明你抓的是另一条请求 —— 找 `findCustInfoByCustCodeAndCustName` 这条，它的 `custName` 是明文。

## 四、填进集成

```
设置 → 设备与服务 → 添加集成 → 搜索「中国燃气」→ 把 5 个值粘进去
```

## 五、常见问题

### ① 抓不到请求

- 确认工具处于 **VPN 抓包模式**（不是 WiFi 代理）
- 确认 **CA 证书已装并信任**
- 小程序要**真的点进去、看到余额**才会发这条请求
- 有些小程序会把流量走 QUIC/UDP，抓包工具里把「QUIC 拦截」打开

### ② 抄错了 `x-mas-app-info`

这个字段最长（150+ 字符），抄错一位就无法鉴权。

**建议用抓包工具的「复制为 cURL」**，粘到记事本里，再分段比对。

### ③ `accessToken` 过期了

```
表现：binary_sensor.gas_sync_ok = off
     集成日志里有 401 / 鉴权失败
解决：重新抓一次 → 设置 → 设备与服务 → 中国燃气 → 选项 → 更新 token
```

### ④ 一台设备只能抓自己的

`custCode` 和 `accessToken` 是绑定的 —— **A 账号的 token 查不了 B 的户号**。

给朋友用，**让他自己抓自己的**。

---

## 六、隐私提醒

```
accessToken 等同于账号登录态 ⚠️
```

- **不要**发到群里、不要提交到公开仓库
- 朋友之间私下传
- 感觉泄露了 → 微信里退出「中燃在线」重登，旧 token 会失效

---

## 七、不想抓包？还有两个办法

**① 小程序里看户号**

「中燃在线」→ 我的 → 缴费记录 / 账户信息里能看到**燃气户号**（10 位数字）和姓名。

**② 但 token 只能抓**

`accessToken` / `userId` / `x-mas-app-info` 这三个**没有网页入口可以查**，只能抓包。
